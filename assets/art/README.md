# Art

Game-ready copies of the Codex art, added when a milestone first uses them. Originals stay in the art hand-off
folder; these are resized and compressed for the browser.

| Folder | Contents | Used from |
|---|---|---|
| `textures/` | seamless ground tiles (1024², JPEG); `TEX-MUD` for mud (M12) | M1 |
| `LEVEL-03-ELEPHANT.webp` | Elephant level picture for the level list and briefing (1536×1024, WebP) | M12 |
| `MENU-BG.webp` | main menu background (1672×941) | M4 |
| `STAGE-01.webp` | Stage 1 card (1536×1024) | M4 |
| `LEVEL-01-LION.webp`, `LEVEL-02-LEOPARD.webp` | level pictures for the level list and briefing (1536×1024) | M4, M11 |
| `GUO-1-BRIEFING` … `GUO-4-TIP.webp` | Chief Warden Guo for briefings, hints and result quips (longest side 640) | M4 |
| `PORTRAIT-*.webp` | the six profile portraits (longest side 640) | M4, M7 |
| `ICON-UNIT-*`, `ICON-DEF-*`, `ICON-ABILITY-*`, `ICON-FORMATION-*.webp` | unit, structure, ability and formation icons (256²) | M4, M7 |

The pictures before M12 were made after their milestones had shipped with placeholders and were only copied in at M12.
Result, achievement and movie art follow with M15 and later.
