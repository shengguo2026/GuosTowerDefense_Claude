# Assets

- `art/`: 2D art from Codex (icons, portraits, backgrounds, result artworks, textures), added when a milestone first
  uses it. The original photo used to create Chief Warden Guo is never stored here or shown in the game.
- `audio/`: CC0 sound effects and music, with a licence list (from M4).
- `video/`: intro and stage movies (from R3).
